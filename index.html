그룹으로 묶어 관리

지점별·거래처별로 그룹을 만들어 두면, 다음 작업부터는 고르기만 하면 돼요.

이미지 + 문구 콘텐츠 구성

이미지와 문구를 원하는 순서로 구성해 저장해요. 이미지 묶음 옵션도 선택할 수 있어요.

즉시 · 예약 실행

지금 바로 진행하거나 시간을 정해 두세요. 예약은 앱이 켜져 있을 때 자동으로 시작돼요.

진행 중에도, 내가 운전대를 잡아요

F9로 안전하게 일시정지하고, 다시 누르면 이어서 진행해요. F11은 즉시 강제 중지예요.

F9일시정지 / 재개
F11강제 중지

속도 3단계 + 무작위 간격

SLOW(안정) · NORMAL(기본) · FAST(빠름) 중에서 고르세요. 대상자 사이 대기 시간은 매번 조금씩 달라져, 일정한 간격으로 고정되지 않아요.

운영 이력 · 리포트

작업 결과를 표로 보고 CSV로 저장해요. 상태·키워드로 걸러 볼 수도 있어요.

실패와 미처리 대상만 추려서 재처리 목록을 한 번에 만들어요.

자동 백업 · 공용 PC 모드

빠르고 정확하게

카센더는 내 PC에서 동작하는 로컬 설치형 도구예요. 그래서 속도와 통제권을 직접 쥐어 드려요.

3단계

속도 선택 · 무작위 간격

SLOW · NORMAL · FAST 중에서 고르고, 대상자 사이 간격은 매번 달라져요. 처음 처리하는 대상자에게는 조금 더 여유를 두기도 해요.

F9 / F11

언제든 멈출 수 있어요

일시정지는 진행 중인 항목을 마무리한 뒤 안전하게 멈추고, 강제 중지는 즉시 멈춰요. 중지하면 어디까지 처리됐는지도 구분돼요.

LOCAL

내 PC에 저장돼요

대상자·콘텐츠 데이터는 내 PC에 저장돼요. 공용 PC 모드에서는 백업을 최신 1개만 남기고, 앱 삭제 시 데이터 초기화도 지원해요.

사용 전 꼭 확인해 주세요. 대상자의 동의 여부와 관련 서비스 이용 정책 준수는 사용자의 책임이에요. 카센더는 카카오의 공식 서비스가 아니에요. 처음에는 소량으로 테스트한 뒤 늘려 가길 권해요.

자주 묻는 질문

궁금한 점을
미리 답해 드려요

카센더는 무엇인가요?

반복적인 업무 커뮤니케이션을 효율적으로 관리할 수 있도록 지원하는 로컬 설치형 생산성 도구예요. 대상자 관리, 콘텐츠 구성, 운영 이력 관리 기능을 제공해요.

어떤 환경에서 쓸 수 있나요?

Windows 10/11 PC에서 동작하는 로컬 설치형 프로그램이에요.

카카오 로그인은 왜 필요한가요?

카카오 로그인은 베타 사용자 식별 및 서비스 접근 제어를 위해서만 사용돼요. 카센더는 카카오의 공식 서비스가 아니에요.

작업 중에 멈출 수 있나요?

네. F9로 일시정지하면 진행 중인 항목을 마무리한 뒤 멈추고, 다시 F9를 누르면 이어서 진행해요. F11은 즉시 강제 중지예요.

명단은 어떻게 불러오나요?

엑셀 파일과 PDF 표를 가져올 수 있고, 복사한 표를 붙여넣어 여러 명을 한 번에 추가할 수도 있어요. 가져오기 전에 미리보기로 내용을 확인해요.

실패한 대상자만 다시 처리할 수 있나요?

네. 운영 이력 화면에서 리포트를 열고 [실패+미처리 재처리 목록 만들기]를 누르면 해당 대상자만 모아 새 작업 목록이 만들어져요.

데이터는 어디에 저장되나요?

대상자·그룹·콘텐츠·운영 이력은 내 PC에 저장돼요. 다른 PC로 옮길 때는 [설정 내보내기]로 파일을 만들고, 새 PC에서 [설정 가져오기]를 선택하면 돼요. 오류 신고 시 DB 포함 여부는 매번 직접 선택해요.

업데이트는 어떻게 하나요?

앱이 새 버전을 확인하고, 앱을 종료할 때 설치를 진행해요. 최신 설치 파일은 언제든 GitHub 릴리스에서 받을 수 있어요.
